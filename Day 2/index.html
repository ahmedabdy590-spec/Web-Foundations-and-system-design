About QuickNotes

QuickNotes helps you capture ideas and reminders in one simple place. Use it to keep track of the notes you want to remember throughout your day.

How to use QuickNotes

  1. Open QuickNotes.
  2. Write a short title for your note.
  3. Enter your note and save it so you can find it later.

Features

  • Create notes for ideas and reminders.
  • Keep your notes organized in one place.
  • Find important information quickly.

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
